### madi
m ma mad madi 
---- OVERVIEW ----
madi                 - madi related functions
---- DESCRIPTION ----
madi	sync        < 1=master, 0=slave >
madi	in          < 1=coax,   0=optical >
madi	56ch        < 1=56Ch,   0=66Ch >
madi	tx48k       < 1=48K,    0=96K >
madi	input       < uTrackInputStartChannel,  madiInputStartChannel  >
    	            < uTrackInputStartChannel>   --to analog --
madi	output      < uTrackOutputStartChannel, madiOutputStartChannel >
madi	thru        < madiInputStartChannel,    madiOutputStartChannel >
madi	setfs       < 44, 48, 88, 96>
madi	id          Read madi ID 
madi	rev         Read madi Revision
madi	getfs       Read madi FS 
madi	getlock     Read madi Lock bit 
madi	getconn     Read madi Conn bit 
madi	get48k      Read madi rx48k bit 
madi	get56ch     Read madi rx56ch bit 
madi	info        read digital board ID from shift register
madi	reg         read madi register(in hex) value
